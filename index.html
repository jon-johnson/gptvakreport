Event loader

Single-file GitHub Pages app for Vakaros RaceSense analysis. It attempts direct loading from the player URL and also supports pasted HAR/JSON when CORS or private APIs block direct access.

Ready. Direct loading depends on the Vakaros endpoints allowing browser access from this page.

Fallback import

Open the Vakaros player, install the discovery snippet in DevTools Console, refresh/replay the race, then paste captured JSON or an exported HAR here.

Accepted point fields include lat/lon/time/sog/heel/boat/name/race/startTime. The parser also searches nested JSON/HAR responses.

Leg detection
